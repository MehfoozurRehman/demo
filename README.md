# demo

Two static HTML pages, an index and a services page, that look like the start of a small marketing site.

**Status:** Stub. The repo holds two HTML files with no styles, scripts, or assets, and each page's body is one word.

## The problem

The code does not show a project goal. It is a bare starting point for a multi-page static site.

## What it does

- `index.html` is a page whose body reads "index".
- `services.html` is a page whose body reads "service".
- Both pages share the same head: UTF-8 charset, a viewport meta tag, and the page title "Document".

## How it's built

- Plain HTML with no build step, no framework, and no package manifest.
- The pages link to each other only by file name, and no navigation exists yet.

## Running it locally

Open `index.html` in a browser. There is nothing to install.
